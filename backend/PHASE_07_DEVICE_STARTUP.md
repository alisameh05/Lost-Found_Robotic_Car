## Startup bundle v1

- `profile.json` uses [QualificationProfile in API §10.1](../docs/API.md#101-required-configuration-not-fallback-timers) with `evidence_kind` set to `Device`. Hash the exact bytes of `evidence.json` and `interfaces.json` into the two profile references. Use a new ID for a newly qualified profile.
- `interfaces.json` uses `version: 1` and `kind: "Device"` with the inventory keys above. An unselected entry is `null`. Every robot selection declares `identity`, integer `protocol_version` and `contract_sha256`. Enter the HC-05 `windows_port`, `serial_baud`, `data_bits`, `parity`, `stop_bits_x2`, `flow_control`, `uno` build, and `logical_output_sha256`. The ESP32-CAM entry includes `variant`, private IPv4 `address`, explicit `port`, and `esp32_cam` build. A build has `target`, `firmware_sha256` and name-to-version maps for `tools`, `cores` and `libraries`. A pin is an exact dotted version or full Git commit SHA. Proximity declares `source`, `transport`, `endpoint_id` and `unit: "mm"`. Each optional input declares its exact `identity` and `profile_sha256`. The Windows and protected network entries refer to local evidence artifacts.
- `evidence.json` uses `version: 1` and `kind: "Measured"`. Include the `profile_id`, `interfaces_sha256`, and a `measurements` object keyed by each numeric qualification bound except `protocol_version`. Each measurement contains the configured integer `value` and `artifact_sha256` supporting that value in the corresponding API units. The `stop_budget` contains `software_ms`, positive `mechanical_margin_ms`, and its own `artifact_sha256`. The budget covers the largest required-path detection deadline, outstanding challenge lifetime, and firmware expiry. The software allocation plus mechanical allowance must fit within 500 ms. The app checks the allocation. The external wheel-stop measurement remains a separate acceptance check.
- Each measurement artifact is version 1 with kind "DeviceMeasurement", the same profile ID and interface SHA-256, a procedure ID, the SHA-256 of the recorded result, and the supported bounds in a name-to-integer map. The artifact supporting the stop budget also records the same software and mechanical allowances in stop_allowance. The loader follows that chain to the recorded result and checks each referenced value.
- Place referenced measurement, protocol, logical output, local input, Windows, and network evidence under `device/artifacts/<lowercase-sha256>`. The loader checks the exact bytes and accepts local files up to 256 KiB each. Firmware hashes are checked against observations by the applicable adapters. Supply evidence for this selection. The test bundle only exercises validation and presentation.

Stop the disarmed backend before changing the bundle. Reload all three manifests together at restart. A changed manifest or evidence artifact invalidates its previous reference. The data-root owner lock preserves coordinated startup and the application reconciles interrupted records through the existing recovery path. Until a compatible adapter has current observations, the affected connection remains unavailable. The command, camera, and proximity implementations arrive in #90–#92.
